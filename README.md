# Northstar Studio — Responsive Navigation

A polished, responsive landing page built with semantic HTML5, CSS3, and vanilla JavaScript. It features a desktop navigation bar, an animated mobile slide-in menu, and a matching hero section.

## Features

- Responsive desktop, tablet, and mobile layouts
- Mobile navigation with animated hamburger/close icon
- Menu closes when a link is selected, the user clicks outside, or Escape is pressed
- Accessible labels, expanded state, focus styles, and reduced-motion support
- Smooth anchor navigation to the page sections
- No frameworks, build tools, or dependencies required

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript

## Run locally

1. Download or clone this project.
2. Open `index.html` in a modern web browser.

For a local development server, run a static HTTP server in this folder, such as `python -m http.server 8000`, then visit `http://localhost:8000`.

The page uses Google Fonts when an internet connection is available and falls back to system sans-serif fonts otherwise.
